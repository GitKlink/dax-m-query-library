# Public Repository Data Policy

This is a public repository. Examples, fixtures, tests, screenshots, comments, and documentation must be safe to publish.

Use synthetic or deliberately public data.

Do not commit:

- personal or employee data;
- remuneration outcomes or internal workforce data;
- confidential company-specific rules/names not intended for publication;
- proprietary survey/vendor data;
- private SharePoint/Microsoft List URLs;
- secrets, passwords, tokens, keys, connection strings, or credentials.

When adapting an internal use case into a reusable feature, generalize identifiers and examples before committing them.
