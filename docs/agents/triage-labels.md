# Triage Labels

Preferred workflow labels for Ask Matt / engineering skills:

- `needs-triage` — issue has not yet been classified.
- `needs-info` — implementation is blocked on missing information.
- `ready-for-agent` — sufficiently specified for agent implementation.
- `ready-for-human` — requires human decision/review/action.
- `wontfix` — deliberately not proceeding.

Use existing equivalent repository labels rather than creating duplicates if the label set changes later.

These labels are the canonical semantic mapping for repository automation and triage workflows. If a label is not yet created in GitHub, create it before relying on that state in an automated workflow.
